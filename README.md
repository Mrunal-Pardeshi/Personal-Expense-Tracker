# ExpenseMate – Personal Expense Tracker

A simple and responsive web application to manage personal income, expenses, monthly budgets and financial reports.

### Features
- Add, edit and delete transactions.
- Track income, expenses and available balance.
- Search and filter transactions.
- Set and monitor monthly budgets.
- View expense charts and reports.
- Save data using LocalStorage.
- Responsive desktop and mobile interface.

### Tech Stack
React.js, JavaScript, Tailwind CSS, Vite, Recharts, Lucide React and LocalStorage.
